# 🚀 Creative Agency Landing Page

A modern and responsive **Creative Agency Landing Page** built using **React.js**, **Vite**, and **Tailwind CSS**. The project focuses on clean UI, reusable components, and responsive design with smooth animations and glassmorphism effects.

---

## 📌 Features

* 🎨 Modern and attractive UI
* 📱 Fully Responsive Design
* ⚡ Built with React + Vite
* 💨 Styled using Tailwind CSS
* 🧩 Reusable Components
* 🌈 Gradient Text & Glassmorphism Effects
* 🖼️ Custom Images and Backgrounds
* 📝 Testimonial Section
* 📊 Stats & Feature Cards
* 📞 Contact Section
* 🦶 Footer with Navigation & Social Links

---

## 🛠️ Tech Stack

* React.js
* Vite
* Tailwind CSS
* JavaScript (ES6+)
* Lucide React Icons

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/creative-agency.git
```

Go to the project folder:

```bash
cd creative-agency
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
